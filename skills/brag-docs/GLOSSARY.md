# Brag docs

Language for the living record of someone’s work impact.

## Language

**Brag document**:
The durable record of accomplishments (usually one file or page per year). The default home is a local markdown file.

**Entry**:
One accomplishment written as action → result → evidence.

**Evidence**:
Proof that backs an entry (metric, ticket or PR reference, observable outcome, or qualitative context). Missing proof is marked `(evidence needed)` — an entry with a gap is still worth saving.

**Store**:
Where or how this run delivers entries: `markdown` (local file), `notion` (page append), or `chat-only` (pasteable markdown, no persistence).

**Store owner**:
Who owns the device or account holding the **Store**: `personal` or `work`. A personal store holds only generalized entries.

**Review pack**:
A review-ready draft built from existing entries: top picks grouped by impact theme, each written as a STAR narrative.
